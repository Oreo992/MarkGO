# MarkGo Brand Assets

`markgo-app-icon.png` is the selected MarkGo app icon direction.
`MarkGo.icon` is an Icon Composer source package for macOS 26-style Liquid Glass rendering.
`markgo-liquid-glass-preview.png` is the 1024 px export generated from `MarkGo.icon` with Xcode 26.4.1 `ictool`; this is the source used for the current Xcode AppIcon sets.

The icon represents Markdown becoming ready to go: a teal folded page moving forward, a white `#` markdown cue, and a small coral accent for a light, independent-app feel.

Primary colors:

- Teal: `#10BFAF`
- Mint: `#BDE6D7`
- Coral: `#FF6D55`
- Ink: `#1D242C`
- Paper: `#FFF9EE`
